# ToDoList

Prosta aplikacja do zarządzania zadaniami (CRUD).

## Technologie
- Backend: ASP.NET Core Web API (C#)
- Frontend: HTML + JavaScript
- Baza danych: PostgreSQL (Docker)

## Uruchomienie

1. Uruchom bazę danych:
```
docker-compose up -d
```

2. Uruchom backend:
```
cd Backend
dotnet run
```

3. Otwórz `Frontend/index.html` w przeglądarce.
